PART 2 - QUESTION 1: Creating and Working on a Git Branch

# 2. Navigate into the cloned repository folder

# 3 & 4. Create a new Git branch called 'Markdown' and checkout to it

# 5. Check the status of the current repository and confirm on branch 'Markdown'

PART 2 - QUESTION 2: Merging Branches and Cleanup
================================================================================

# 1. Checkout back to the master branch

# 2. Merge the Markdown branch into master

# 3. Push the merge up to GitHub master branch
git push origin master

# 4. Delete the local Markdown branch

# 5. View git log in oneline format
